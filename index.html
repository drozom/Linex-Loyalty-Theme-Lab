design.md — live

You're viewing an Aurora direction — this token system belongs to Flat accent, not Aurora. Aurora fixes its own gradient palette inside its own file; it does not read from these custom properties, and design.md does not describe it.

Every colour on this page resolves from this block. Change these values and the whole site changes — nothing else in the codebase names a colour.

How these values were set

Each accent was measured against every surface it lands on — page, card, tinted band, dark band, and its own fill. Any pair below WCAG AA was shifted in lightness, keeping hue and chroma, until it passed. The lowest pair in the finished system is 4.50.
